잘린 근거는 검색되지 않는다

오버랩: 보험과 그 비용

창이 S − O씩 전진한다

청크 수   ≈ N / (S − O)
중복률    ≈ S / (S − O) − 1

S=100, O=40 → +67%

S=300, O=60 → +25%

경계에 걸린 문장이 오버랩보다 짧으면 적어도 한 청크에 온전히 들어간다

실무 기본값: 크기의 10~20%

계산을 학생에게 시킨다. 30,000자, S=300, O=60 → 청크 125개, 37,440자, +24.8% (Challenge C2 정답).

임베딩 API가 유료라면 이 비율이 그대로 비용이다.

부록 B · C1 · C2 정답

function fixedChunks(text, size, overlap = 0) {
  if (overlap >= size) throw new Error('overlap은 size보다 작아야 한다');
  const chunks = [];
  const step = size - overlap;
  for (let start = 0; start < text.length; start += step) {
    const end = Math.min(start + size, text.length);
    chunks.push({ start, end, text: text.slice(start, end) });
    if (end === text.length) break;
  }
  return chunks;
}
console.log(fixedChunks('가나다라마바사아자차', 4, 1).map((c) => c.text));

const doc = 'x'.repeat(30000);
const total = (cs) => cs.reduce((s, c) => s + c.end - c.start, 0);
const a = fixedChunks(doc, 300, 0), b = fixedChunks(doc, 300, 60);
console.table([{ overlap: 0, n: a.length, chars: total(a) }, { overlap: 60, n: b.length, chars: total(b) }]);
console.log(`증가율 ${((total(b) / total(a) - 1) * 100).toFixed(1)}%`);

왜 이렇게 푸는가: end === text.length에서 멈추지 않으면 마지막 청크가 이전 청크의 부분집합인 꼬리 조각이 여러 개 생긴다. overlap ≥ size 검사는 무한 루프 방지다.

C2 기대값: 100개/30,000자 → 125개/37,440자, +24.8%. 공식 S/(S−O)−1 = 25%와의 차이는 마지막 청크가 짧아서다.

부록 B · C3 정답

function sentenceSpans(text) {
  const spans = [];
  const re = /[.!?。]+["')\]]?(?=\s|$)\s*|\n+/g;
  let last = 0, m;
  while ((m = re.exec(text)) !== null) {
    const end = m.index + m[0].length;
    if (end > last) spans.push([last, end]);
    last = end;
  }
  if (last < text.length) spans.push([last, text.length]);
  return spans;
}
const sample = '평점이 4.0 이상이다. 지급액은 50%다!\n다음 줄? 끝';
console.log(sentenceSpans(sample).map(([s, e]) => sample.slice(s, e)));

핵심: 전방탐색 (?=\s|$)로 “부호 뒤에 공백이나 문서 끝”일 때만 자른다. 4.0의 마침표 뒤에는 숫자가 오므로 자르지 않는다.

split을 쓰면 위치 정보가 사라진다. 위치를 유지해야 11주차 인용 하이라이트가 된다는 점을 강조한다.

const docById = Object.fromEntries(corpus.documents.map((d) => [d.id, d]));

function survivalRate(cfg) {
  let kept = 0, total = 0;
  for (const item of golden.items) for (const ev of item.evidence) {
    const cs = chunk(docById[ev.doc].text, cfg);
    if (cs.some((c) => c.text.includes(ev.quote))) kept++;
    total++;
  }
  return kept / total;
}

for (const strategy of ['fixed', 'recursive'])

부록 B · C5 정답

import { chunk } from '/assets/js/core/chunker.js';
const corpus = await (await fetch('/assets/data/corpus/corpus.json')).json();
const doc = corpus.documents.find((d) => d.id === 'facility-rules');

function contextualize(doc, chunks) {
  return chunks.map((c) => ({ ...c, embedText: `[${doc.title}] ${c.text.trim()}` }));
}
const out = contextualize(doc, chunk(doc.text, { strategy: 'recursive', size: 120 }));
console.table(out.map(({ start, end, embedText }) => ({ start, end, embedText })));
console.log('위치 보존:', out.every((c) => doc.text.slice(c.start, c.end) === c.text));

왜: 임베딩할 텍스트(embedText)와 인용할 원문 위치(start/end)를 분리한다. 원문 text를 덮어쓰면 11주차 하이라이트가 어긋난다.

이 기법을 contextual chunk header라고 부른다. 5주차에 실제로 유사도가 오르는지 확인한다.
