검색증강생성(RAG) 시스템 구축

문서 파싱부터 평가까지, 동작하는 RAG를 만든다. 설치 없이 이 페이지에서 청킹·임베딩·검색을 직접 돌려 보고, 마지막에는 자신이 만든 시스템을 숫자로 측정한다.

학생용 — 문서 + 실습 교사용 — PPT 슬라이드 + 교사 노트

이 과정이 다른 점

브라우저에서 직접 실습한다

파이썬 설치도, 서버도 필요 없다. 임베딩 모델이 브라우저 안에서 돌아가므로 슬라이더를 움직이면 결과가 바로 바뀐다.

평가까지 간다

튜토리얼에서 멈추지 않는다. 골든셋을 만들고 Recall@k, nDCG, Faithfulness로 내 RAG가 얼마나 좋은지 측정한다.

고장난 RAG를 고친다

표가 깨진 문서, OCR 오류, 잘린 문장. 일부러 망가뜨린 예제에서 증상을 보고 원인을 추적하는 연습을 한다.

시작하기 전에

  • 최신 크롬·엣지를 쓴다. 5주차부터 임베딩 모델(약 120MB)을 처음 한 번 내려받는다. 이후에는 브라우저 캐시에서 바로 불러온다.
  • LLM API 키는 본인 것을 쓴다. 키는 이 탭의 sessionStorage에만 저장되고 탭을 닫으면 사라진다. 서버로 전송되지 않는다.
  • 모든 실습 데이터는 같은 문서셋이다. 학과 안내문과 이 과정의 이론 교안 자체를 문서로 쓴다. 정답을 아는 문서로 실험해야 검색이 맞았는지 판단할 수 있다.

학생용과 교사용 화면은 모두 3단이다. 왼쪽은 강의 목록, 가운데는 강의 내용(학생용은 문서, 교사용은 16:9 슬라이드와 교사 노트), 오른쪽은 실습 결과다. 교수자는 교사용 허브에서 주차별 슬라이드, Challenge 정답, 평가 루브릭을 본다.
