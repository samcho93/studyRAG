시작하기 전에

  1. 최신 크롬·엣지를 쓴다. 5주차부터 임베딩 모델(약 120MB)을 처음 한 번 내려받고, 이후에는 브라우저 캐시에서 바로 불러온다.
  2. 화면 구성: 왼쪽 강의 목록 · 가운데 강의 내용 · 오른쪽 실행 결과. 경계선을 끌어 너비를 바꿀 수 있다.
  3. LLM API 키는 본인 것을 쓴다. 키는 이 탭의 sessionStorage에만 저장되고 탭을 닫으면 사라진다. 어떤 서버로도 보내지 않는다.
  4. 모든 실습은 같은 문서셋을 쓴다. 학과 안내문과 이 과정의 이론 교안 자체가 문서다. 정답을 아는 문서로 실험해야 검색이 맞았는지 판단할 수 있다.
